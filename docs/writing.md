# 문서와 명세 작성 지침

ASD-STE100의 명확성 원칙을 한국어 문서에 적용한다. 이 지침은 통제 영어 표준의 한국어 인증 규칙이 아니다.

- 한 문장에는 한 가지 내용만 쓴다.
- 같은 개념에는 같은 용어를 쓴다. 새 용어와 약어는 처음 쓸 때 설명한다.
- 주체와 동작을 명확하게 쓴다. 조사와 서술어를 생략한 명사 나열을 피한다.
- 조건을 먼저 쓰고 그 조건에서 수행할 동작과 결과를 쓴다.
- 수용 기준에는 입력·조건·관찰 가능한 결과를 적는다.
- 한 단계에는 한 가지 행동을 쓴다. 순서가 있으면 번호를 붙인다.
- 사실·추론·미결정을 구분한다. 각 판단에는 근거 위치를 단다.
- '적절히', '필요시', '정상적으로' 같은 표현은 판단 조건과 결과로 바꾼다.
- 간결하게 쓰되 예외·오류 조건·단위·부정의 적용 범위는 생략하지 않는다.

예: '실패 시 적절히 처리한다' 대신 '저장 요청이 실패하면 입력값을 유지한다. 화면에 오류 메시지를 표시한다.'라고 쓴다.

생성 역할은 이 지침으로 문장을 쓴다. 비평 역할은 의미가 불명확한 문장을 지적한다. 문장 길이와 금칙어만으로 품질을 자동 판정하지 않는다.

근거: [ASD Simplified Technical English](https://asd-ste100.org/)의 기술 문서 명확성 원칙을 참고한다. 자연스러운 한국어의 목표는 [fluent-korean 안내](https://github.com/snflkd/fluent-korean)의 의미 전달 원칙을 참고한다. 외부 플러그인 설치를 전제로 하지 않는다.
